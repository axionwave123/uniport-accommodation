# PROJECT_CONTEXT
Product: UNIPORT student accommodation discovery platform (Port Harcourt, Nigeria), expanding later to a city-wide real-estate marketplace.
Workflow: Claude = architecture/design/code preparation. Grok = writes to GitHub, builds, verifies. User = approvals.
Launch rules: growth first; agents pay nothing; platform collects NO rent/commission; agents publish instantly; students contact agents directly.
Core model: Property (parent) -> Rooms (availability is ROOM-level). 1 overview video per property; separate photos/videos per room.
Discovery: available rooms near UNIPORT by REAL ROAD distance + road travel time. Normal + satellite map.
Engagement: named agent + profile, direct contact, follow agents, new-listing notifications, ratings/reviews, inspection request for a SPECIFIC room, listing view tracking.
Honesty rule: no fake listings, reviews, view counts, availability, or mocked features reported as done.
